# AdvoInsight Dashboard

Dashboard analisis pengaduan mahasiswa berbasis web.

## Fitur
- Ringkasan jumlah pengaduan
- Filter kategori dan status
- Visualisasi data menggunakan Plotly
- Tabel data pengaduan
- Ekspor data ke CSV

## Teknologi
- Python
- Streamlit
- Pandas
- Plotly

## Menjalankan aplikasi
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Catatan
Data yang digunakan adalah data sintetis untuk demonstrasi,
bukan pengaduan mahasiswa sungguhan.

## Prinsip IMK
- Visibility of system status
- Feedback
- Consistency
- Affordance
- Visual hierarchy
